Quick start

Install DPDK and dependencies with ./deps.sh, then build with DPDK support:

./configure CFLAGS="-O3" CXXFLAGS="-std=c++11 -O3" \
  --enable-dpdk --enable-intel-cpu --disable-dynamic-linking \
  --enable-bound-port-transfer --enable-flow \
  --disable-task-stats --disable-cpu-load
make

Then describe a pipeline in the Click language and run it:

FromDPDKDevice(0) -> Counter -> ToDPDKDevice(1);
